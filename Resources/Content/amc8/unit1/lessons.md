## 유닛 1. 세는 법 1 (Counting I)

### 1-1. 합의 법칙과 곱의 법칙 (Addition & Multiplication Principles)

**왜 배우나**
경우의 수 문제는 결국 "더할까, 곱할까"의 판단이다. 이걸 틀리면 뒤에 나오는 모든 공식이 무너진다.

**기초 설명**
- **합의 법칙**: 동시에 일어날 수 없는 경우들이 있을 때 (A **또는** B), 경우의 수를 **더한다**.
- **곱의 법칙**: 단계가 연달아 있을 때 (A를 하고 **이어서** B), 각 단계의 선택지 수를 **곱한다**.
- 곱의 법칙의 조건: 앞 단계에서 무엇을 골랐든 다음 단계의 선택지 **개수**가 같아야 한다. 개수가 달라지면 경우를 나눠서 각각 곱하고 더한다.
- 판단 요령: 문장에 "그리고, 이어서, 각각"이 숨어 있으면 곱, "또는(겹치지 않음)"이면 합.

**직관 예시**
티셔츠 3벌, 바지 2벌로 코디하는 방법. 티셔츠마다 바지 2가지가 붙으니까 나무 그림을 그리면 가지가 3 × 2 = 6개.
반대로 티셔츠 3벌과 후드티 2벌 중 **윗옷 하나**를 고르는 건 3 + 2 = 5. 둘 중 하나만 입으니까 합.

**예제 풀이**

예제 1. 각 자리 숫자가 모두 다른 세 자리 수의 개수
1. 백의 자리: 0 불가 → 1~9 중 9가지
2. 십의 자리: 0~9 중 백의 자리 숫자만 빼고 → 9가지
3. 일의 자리: 앞의 두 숫자 빼고 → 8가지
4. 9 × 9 × 8 = **648**

예제 2. 각 자리 숫자가 모두 다른 세 자리 **짝수**의 개수
1. 제약이 센 자리부터 정한다: 일의 자리(짝수)와 백의 자리(0 불가)가 둘 다 0과 얽혀 있다.
2. 경우 A, 일의 자리가 0: 일 1가지, 백 9가지(1~9), 십 8가지 → 72
3. 경우 B, 일의 자리가 2, 4, 6, 8: 일 4가지, 백 8가지(0과 일의 자리 숫자 제외), 십 8가지 → 256
4. 72 + 256 = **328**
5. 왜 나눴나: 일의 자리가 0이냐 아니냐에 따라 백의 자리 선택지 개수가 9와 8로 달라지기 때문.

예제 3. 4자리 비밀번호, 첫 자리 0 불가, 마지막 자리 짝수
9 × 10 × 10 × 5 = **4500**

**고급 팁**
- **제약이 가장 센 칸부터** 채운다. 예제 2에서 십의 자리부터 정하면 꼬인다.
- 앞 선택에 따라 다음 선택지 개수가 바뀌면 **그 원인(대개 0)으로 경우를 나눈다.**
- 경우가 30개 이하로 보이면 공식 고민하지 말고 **사전순으로 전부 써라**. 사전순으로 쓰면 빠뜨리지 않는다. AMC 8에서 이게 가장 빠를 때가 많다.

**함정**
- 첫 자리에 0을 넣음
- "서로 다른" 조건을 읽고도 곱할 때 반영 안 함
- 동시에 할 수 없는 선택(윗옷 하나)을 곱함

### 1-2. 여사건 (Complementary Counting)

**왜 배우나**
"적어도 하나"를 직접 세면 1개, 2개, 3개… 경우가 폭발한다. 반대쪽은 대개 한 줄이다.

**기초 설명**
- 원하는 것 = 전체 − 원하지 않는 것
- 확률로는 $P(A) = 1 - P(\text{A가 아님})$
- 신호어: 적어도 하나(at least one), ~가 아닌(not), 모두 ~인 것은 아닌(not all), 최소 한 번

**직관 예시**
동전 3개에서 앞면이 적어도 하나 나오는 경우.
- 직접: 앞면 1개(3가지) + 2개(3가지) + 3개(1가지) = 7
- 반대: 전부 뒷면인 경우 1가지 → 8 − 1 = 7
동전이 10개면 직접 세기는 10가지 경우를 다 더해야 하지만, 반대는 여전히 $2^{10} - 1$ 한 줄.

**예제 풀이**

예제 1. 세 자리 수 중 숫자 7이 적어도 하나 들어간 수
1. 전체 세 자리 수: 100~999 → 900개
2. 7이 하나도 없는 수: 백 8가지(0, 7 제외) × 십 9가지 × 일 9가지 = 648
3. 900 − 648 = **252**

예제 2. 동전 5개를 던질 때 앞면이 적어도 2개 나올 확률
1. 전체 $2^5 = 32$
2. 반대 = 앞면 0개(1가지) 또는 1개(5가지) = 6
3. 32 − 6 = 26 → $\frac{26}{32} = \frac{13}{16}$

예제 3. 1~100 중 숫자 5가 들어가지 **않는** 수와 들어가는 수
1. 1~99를 두 자리 00~99로 보면, 5 없는 것: 9 × 9 = 81개, 그중 00 빼면 80개
2. 100은 5가 없음 → 81개
3. 5가 들어가는 수: 100 − 81 = **19**
4. 직접 확인: 일의 자리 5(5, 15, …, 95) 10개 + 십의 자리 5(50~59) 10개 − 55 중복 1개 = 19. 두 방법 일치.

**고급 팁**
- 확률에서 "적어도 하나 성공"은 거의 항상 **1 − (전부 실패)**. 전부 실패는 곱 한 번이다.
- 여사건도 복잡하면 원래 방향이 나을 수 있다. **두 방향 중 경우가 적은 쪽**을 고른다.
- 기하에서도 똑같다: 색칠된 넓이 = 전체 − 안 칠해진 부분 (유닛 5-2).

**함정**
- 전체를 잘못 셈: 세 자리 수는 999개가 아니라 900개
- 여사건이 정확히 반대인지 확인 안 함: "적어도 2개"의 반대는 "0개 또는 1개"이지 "1개"가 아님

### 1-3. 포함배제 (Inclusion-Exclusion)

**왜 배우나**
"A 또는 B인 것", 배수 개수, 벤 다이어그램 문장제가 매년 나온다.

**기초 설명**
- 두 집합: $|A \cup B| = |A| + |B| - |A \cap B|$. 겹친 부분을 두 번 셌으니 한 번 뺀다.
- 세 집합: $|A \cup B \cup C| = |A|+|B|+|C| - |A\cap B| - |B\cap C| - |C\cap A| + |A\cap B\cap C|$. 세 겹 부분은 세 번 더해지고 세 번 빠졌으니 한 번 다시 더한다.
- 1부터 N까지 k의 배수 개수 = $\lfloor N/k \rfloor$ (N을 k로 나눈 몫)

**직관 예시**
반 30명, 축구 좋아함 18명, 농구 좋아함 15명, 둘 다 7명.
- 둘 중 하나라도: 18 + 15 − 7 = 26
- 아무것도 안 좋아함: 30 − 26 = 4
벤 다이어그램에 가운데 7부터 쓰고, 축구만 11, 농구만 8을 채우면 한눈에 보인다.

**예제 풀이**

예제 1. 1~100 중 2의 배수 또는 3의 배수
1. 2의 배수 50, 3의 배수 33
2. 둘 다 = 6의 배수 16
3. 50 + 33 − 16 = **67**. 둘 다 아닌 수는 100 − 67 = 33

예제 2. 1~1000 중 2, 3, 5 어느 것으로도 나누어떨어지지 않는 수
1. 한 개씩: 500 + 333 + 200 = 1033
2. 두 개씩(6, 10, 15의 배수): 166 + 100 + 66 = 332
3. 세 개(30의 배수): 33
4. 2, 3, 5 중 하나라도: 1033 − 332 + 33 = 734
5. 셋 다 아닌 수: 1000 − 734 = **266**

예제 3. 40명 중 수학 좋아함 25, 과학 좋아함 20, 둘 다 안 좋아함 5. 둘 다 좋아하는 사람은?
1. 하나라도 좋아함: 40 − 5 = 35
2. 35 = 25 + 20 − x → x = **10**

**고급 팁**
- "둘 다의 배수"는 **최소공배수의 배수**. 6과 8이면 48이 아니라 24.
- 벤 다이어그램은 **가장 안쪽(전부 겹친 부분)부터** 채운다.
- "정확히 하나만"은 $|A| + |B| - 2|A \cap B|$.
- 범위가 1부터가 아니면: 50~150 사이 k의 배수 = $\lfloor 150/k \rfloor - \lfloor 49/k \rfloor$

**함정**
- 최소공배수 대신 그냥 곱함
- 몫 계산 실수: 1~100 중 6의 배수는 16개 (17 아님)
- 세 집합에서 마지막에 세 겹을 다시 더하는 것 빠뜨림

### 1-4. 일부러 중복 세고 나누기 (Overcounting)

**왜 배우나**
같은 물건이 섞인 배열, 원형 배치, 악수나 경기 수처럼 "짝"을 세는 문제는 직접 세기 어렵다. 일단 많이 세고 나누는 게 훨씬 쉽다.

**기초 설명**
- 일단 전부 구분된다고 보고 센 다음, **같은 결과가 몇 번씩 중복됐는지**로 나눈다.
- 나누기가 맞으려면 **모든 결과가 똑같은 횟수만큼** 중복돼야 한다.
- 같은 것이 있는 순열: n개 중 같은 것이 a개, b개, …이면 $\frac{n!}{a!\,b!\cdots}$
- 악수(모두 서로 한 번씩): $\frac{n(n-1)}{2}$
- 원순열(원탁, 회전하면 같은 배치): $(n-1)!$
- 목걸이(회전 + 뒤집기도 같음, $n \ge 3$): $\frac{(n-1)!}{2}$

**직관 예시**
LEVEL 재배열.
- 다섯 글자가 다 다르다 치면 5! = 120
- L 두 개를 서로 바꿔도 같은 단어 → 각 단어가 2번씩 세어짐 → ÷2
- E도 마찬가지 → ÷2
- $\frac{5!}{2!\,2!} = 30$

**예제 풀이**

예제 1. MISSISSIPPI 재배열 수
1. 11글자: M 1, I 4, S 4, P 2
2. $\frac{11!}{4!\,4!\,2!} = 34650$

예제 2. 6명이 원탁에 앉는 방법 (회전하면 같은 배치)
1. 일렬이면 6! = 720
2. 원탁에선 한 배치를 6칸 회전한 것이 다 같은 배치 → ÷6
3. 720 ÷ 6 = **120** = 5!
4. 다른 관점: 한 명을 아무 데나 고정하면 나머지 5명 일렬 → 5!

예제 3. 10팀 리그, 각 팀이 다른 모든 팀과 2경기씩
1. 대진 쌍: $\frac{10 \times 9}{2} = 45$
2. 쌍마다 2경기 → **90**

예제 4. 10각형의 대각선 개수
1. 꼭짓점마다 자기 자신과 양옆 이웃을 뺀 7개 꼭짓점으로 대각선
2. 10 × 7 = 70, 대각선 하나를 양 끝에서 두 번 셈 → ÷2
3. **35**. 일반식 $\frac{n(n-3)}{2}$

**고급 팁**
- 위원 뽑기(순서 없음)도 같은 원리: 순서 있게 뽑고 $r!$로 나누면 조합 (유닛 2-1).
- **짝 짓기**: 2n명을 n쌍으로 → $\frac{(2n)!}{2^n \, n!}$. 4명은 3가지, 6명은 15가지.
- 모든 결과가 같은 횟수로 중복되지 않으면 나누기가 깨진다. 예: 목걸이 구슬이 전부 같은 색이면 회전해도 그대로라 중복 횟수가 다르다. 이럴 땐 직접 센다.

**함정**
- 원탁에서 "회전만 같은지, 뒤집기도 같은지" 확인 안 함
- 같은 글자 하나 빼먹고 나눔
- 서로 다른 것을 같다고 보고 나눔

### 1-5. 작은 경우부터 → 규칙 → 점화식 (Small Cases & Recursion)

**왜 배우나**
계단 오르기, 타일 깔기, 조건 있는 문자열처럼 n이 크면 직접 못 센다. 작게 해보면 규칙이 보이고, 규칙의 이유를 잡으면 큰 n도 계산된다.

**기초 설명**
1. $f(1), f(2), f(3)$을 직접 센다.
2. 규칙을 추측한다.
3. **"맨 마지막에 뭐가 오나"로 경우를 나눠서** 규칙의 이유를 확인한다. 이게 점화식(recursion)이다.
4. 점화식으로 표를 채우듯 n까지 계산한다.

**직관 예시**
동전 n개를 일렬로 놓을 때 앞면(H)끼리 붙지 않는 경우의 수.
- n=1: H, T → 2
- n=2: HT, TH, TT → 3
- n=3: HTH, HTT, THT, TTH, TTT → 5
- 2, 3, 5 … 피보나치처럼 보인다. 이유는?
  - 마지막이 T: 앞 n−1개는 조건만 맞으면 아무거나 → $f(n-1)$
  - 마지막이 H: 그 바로 앞은 반드시 T, 그 앞 n−2개는 자유 → $f(n-2)$
  - 그래서 $f(n) = f(n-1) + f(n-2)$

**예제 풀이**

예제 1. 2×n 판을 1×2 도미노로 빈틈없이 덮는 방법 (2×8 판)
1. $f(1) = 1$ (세로 하나), $f(2) = 2$ (세로 둘 또는 가로 둘)
2. 맨 오른쪽 끝을 보면: 세로 도미노 하나가 서 있거나 → 나머지 2×(n−1), 가로 도미노 두 개가 겹쳐 있거나 → 나머지 2×(n−2)
3. $f(n) = f(n-1) + f(n-2)$
4. 1, 2, 3, 5, 8, 13, 21, **34**

예제 2. 추측만 믿으면 안 되는 이유
원 위에 점 n개를 찍고 모든 점을 선분으로 이으면 원이 최대 몇 조각?
- n = 1, 2, 3, 4, 5 → 1, 2, 4, 8, 16
- "2배씩 늘어나네"라고 단정하면 n = 6에서 틀린다. 실제로는 **31**.
- 교훈: 작은 경우로 찾은 규칙은 **이유까지 확인**하거나 한 항 더 계산해서 검증.

예제 3. 1, 2칸씩 오르는 계단 n칸
마지막 한 걸음이 1칸이었거나 2칸이었거나 → $f(n) = f(n-1) + f(n-2)$, $f(1) = 1$, $f(2) = 2$. 도미노와 같은 수열이다. 서로 다른 문제가 같은 점화식이 되는 걸 알아보는 게 실력.

**고급 팁**
- 점화식은 **마지막 단계(또는 첫 단계)로 경우를 나누면** 거의 다 나온다.
- 계산은 표로 쌓아 올린다. 머릿속으로 하면 한 칸 밀린다.
- 한 번에 1, 2, 3칸처럼 선택지가 늘면 점화식 항도 늘어난다: $f(n) = f(n-1) + f(n-2) + f(n-3)$. 시작값은 직접 센다.
- n이 엄청 크면 값 자체가 아니라 **나머지나 일의 자리의 주기**를 찾는 문제다 (유닛 4-2).

**함정**
- 처음 몇 항만 보고 규칙 단정 (예제 2)
- 시작값 $f(1), f(2)$를 잘못 셈
- 점화식 인덱스 한 칸 밀림
