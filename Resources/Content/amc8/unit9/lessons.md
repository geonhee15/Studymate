## 유닛 9. 논리와 전략 (Logic & Strategy)

### 9-1. 거꾸로 풀기 (Working Backwards)

**왜 배우나**
마지막 결과를 알려주고 처음을 묻는 문제는 앞에서부터 식을 세우면 복잡하고, 뒤에서부터 풀면 한 줄이다.

**기초 설명**
- 마지막 상태에서 출발해 연산을 하나씩 **반대로** 적용 (+3 → −3, ×2 → ÷2, "절반을 가져감" → ×2)
- 게임 문제: 이기는 위치를 끝에서부터 표시해 나간다

**직관 예시**
"어떤 수에 3을 더하고 2를 곱하고 5를 뺐더니 25" → 25에 5 더하고(30), 2로 나누고(15), 3 빼면(12) 끝.

**예제 풀이**

예제 1. 위의 직관 예시: **12**

예제 2. 바구니 사과. 첫 사람이 절반보다 1개 더 가져가고, 둘째도 남은 것의 절반보다 1개 더 가져갔더니 1개 남음. 처음 사과 수는?
1. 둘째가 가져가기 전 x: x − (x/2 + 1) = 1 → x/2 = 2 → x = 4. 거꾸로 하면 (1 + 1) × 2 = 4
2. 첫째가 가져가기 전: (4 + 1) × 2 = 10
3. **10개**. 확인: 10 → 6개 가져감 → 4 → 3개 가져감 → 1

예제 3. 돌 21개, 두 사람이 번갈아 1~3개씩 가져가고 마지막 돌을 가져가는 사람이 이김. 먼저 하는 사람의 필승법
1. 끝에서부터: 상대 차례에 돌이 4개면 상대가 뭘 해도 내가 마지막을 가져간다
2. 그래서 상대 차례에 항상 4의 배수가 남게 하면 이긴다
3. 처음에 **1개** 가져가서 20을 남기고, 이후 상대가 k개 가져가면 나는 4 − k개

**고급 팁**
- 게임 문제는 작은 경우(돌 1, 2, 3, 4, 5개)에서 이기는 위치와 지는 위치를 표로 칠하면 규칙이 보인다
- "절반 + 1"처럼 연산이 섞인 건 거꾸로 할 때 순서도 거꾸로

**함정**
- 거꾸로 할 때 연산 순서를 안 뒤집음

### 9-2. 불변량 (Invariants)

**왜 배우나**
"이 조작을 반복해서 ~가 될 수 있나?"는 변하지 않는 값을 찾으면 바로 끝난다.

**기초 설명**
- 조작을 해도 **변하지 않는 값**을 찾는다: 합, 홀짝, 어떤 수로 나눈 나머지, 색칠한 칸의 개수 차이
- 처음과 목표의 불변량이 다르면 → 불가능

**직관 예시**
1 ~ 10 앞에 부호 붙이기 (4-4). 부호를 바꿔도 합의 홀짝이 그대로라 0이 될 수 없다.

**예제 풀이**

예제 1. 칠판에 1~10. 두 수를 지우고 그 차를 적는 걸 반복해 한 수만 남으면 그 수는 홀수인가 짝수인가
1. a, b를 지우고 |a − b|를 쓰면 합은 a + b에서 |a − b|로 바뀜. a + b와 |a − b|는 홀짝이 같다
2. 합의 홀짝 불변. 처음 합 55 (홀)
3. 남는 수는 **홀수**

예제 2. 8 × 8 체스판에서 마주 보는 두 귀퉁이를 뺀 판은 도미노로 덮을 수 없다 (4-4 고급 팁). 불변량 = 흰 칸 수 − 검은 칸 수.

**고급 팁**
- 후보 불변량 순서: 합 → 홀짝 → 3이나 4로 나눈 나머지 → 색칠
- 불변량은 "불가능"을 보이는 도구. 가능하다는 건 직접 예를 만들어 보여야 한다

**함정**
- 조작 한 번에 불변량이 진짜 그대로인지 확인 안 함

### 9-3. 비둘기집 원리 (Pigeonhole Principle)

**왜 배우나**
"반드시 ~가 되려면 최소 몇 개"는 거의 다 이 원리다. 핵심은 **최악의 경우**를 상상하는 것.

**기초 설명**
- 비둘기 n + 1마리를 집 n개에 넣으면 어떤 집에는 2마리 이상
- 일반형: kn + 1마리면 어떤 집에는 k + 1마리 이상
- 풀이법: "운이 최대한 나쁘면 어떻게 되나"를 만들고 거기에 1을 더한다

**직관 예시**
양말 서랍에 세 가지 색. 같은 색 한 켤레(2짝)를 확실히 가지려면? 운 나쁘면 세 짝이 다 다른 색 → 네 번째는 반드시 겹침 → **4짝**.

**예제 풀이**

예제 1. 세 가지 색 양말에서 같은 색 3짝을 확실히 얻으려면 최소 몇 짝?
최악: 색마다 2짝씩 = 6짝 → **7짝**

예제 2. 빨간 공 5개, 파란 공 7개 상자에서 눈 감고 꺼낼 때 빨간 공 2개를 확실히 얻으려면?
최악: 파랑 7개 먼저 다 나옴 → 그다음 빨강 2개 → **9개**

예제 3. 1~10에서 6개를 고르면 합이 11인 두 수가 반드시 있다
1. 합이 11인 쌍으로 집 5개: {1,10}, {2,9}, {3,8}, {4,7}, {5,6}
2. 6개를 고르면 어떤 집에서 2개를 다 고르게 됨

**고급 팁**
- "집"을 무엇으로 잡을지가 핵심 (예제 3에서는 합이 11인 쌍)
- "확실히", "반드시", "보장"이 보이면 최악의 경우부터

**함정**
- 최악의 경우를 덜 나쁘게 상상함 (예제 2에서 파랑을 다 빼지 않음)
- 마지막에 +1 빠뜨림

### 9-4. 극단 원리와 최대·최소 (Extremal Thinking)

**왜 배우나**
"가장 클 수 있는 값", "최소 몇 개"를 물으면 나머지를 극단으로 몰아붙이는 게 정석이다.

**기초 설명**
- 하나를 **최대**로 → 나머지를 **최소**로 (조건 안에서)
- 하나를 **최소**로 → 나머지를 **최대**로
- 끝에서 조건(서로 다름, 양의 정수, 평균 등)을 다 만족하는지 확인

**직관 예시**
피자 8조각을 5명이 나누는데 다들 적어도 1조각. 한 명이 가장 많이 먹으려면 나머지 4명이 1조각씩 → 4조각.

**예제 풀이**

예제 1. 서로 다른 양의 정수 5개의 합이 100. 가장 큰 수의 최댓값은?
1. 나머지 4개를 최소로: 1, 2, 3, 4 → 합 10
2. **90**

예제 2. 서로 다른 양의 정수 여러 개의 합이 100. 개수의 최댓값은?
1. 가장 작은 수부터: 1 + 2 + … + 13 = 91, + 14 = 105 (넘침)
2. 13개면 가능: 1 ~ 12에 마지막을 22로 키움 → 합 100
3. **13개**

예제 3. 8-4 예제 2도 같은 원리 (가장 큰 수를 키우려고 d를 최소로)

**고급 팁**
- 극단으로 몰아붙인 배치가 실제로 조건을 만족하는지 꼭 구체적인 예로 확인
- 최소 개수 문제는 "하나씩 아껴 쓰는" 배치를 직접 만들어 본다

**함정**
- "서로 다른" 조건을 빼먹고 같은 수를 반복
- 양의 정수인데 0을 씀

### 9-5. 논리 퍼즐 (Logic Puzzles)

**왜 배우나**
누가 거짓말쟁이인지, 누가 몇 등인지 같은 문제는 수학 지식 없이 체계만 있으면 풀린다.

**기초 설명**
- **가정하고 모순 찾기**: "A가 참이라면…"을 끝까지 따라가서 모순이 나오면 A는 거짓
- **표 그리기**: 사람 × 속성 표를 만들고 확정된 칸에 O, 불가능한 칸에 X
- 진술끼리 모순되는 쌍을 찾으면 둘 중 정확히 하나가 거짓

**직관 예시**
항상 참만 말하는 기사와 항상 거짓만 말하는 건달. A가 "우리 둘 다 건달이다"라고 했다.
- A가 기사라면: 참을 말해야 하는데 자기가 건달이라고 했으니 모순 → A는 건달
- A가 건달이니 말이 거짓 → "둘 다 건달"이 아님 → B는 **기사**

**예제 풀이**

예제 1. 위의 직관 예시

예제 2. 순위 퍼즐 접근법
1. 사람을 세로, 순위를 가로로 표
2. "A는 B보다 앞"처럼 순서 조건은 화살표 그래프로 그리면 가능한 순서가 바로 보인다
3. 확정된 것부터 X를 채우면 남는 칸이 답

**고급 팁**
- 경우가 2~3개뿐이면 전부 가정해 보는 게 가장 빠르다
- "정확히 한 명만 거짓말"처럼 개수 조건이 있으면 거짓말쟁이를 한 명씩 바꿔가며 확인

**함정**
- 가정을 끝까지 안 따라가고 중간에 결론 냄
- "적어도 한 명"과 "정확히 한 명" 혼동

### 9-6. 선택지 활용, 어림, 시험 전략 (Test Strategy)

**왜 배우나**
같은 실력이어도 전략에 따라 2~3점이 갈린다. 상위권은 이 2~3점 차이다.

**기초 설명**
- **오답 감점 없음** → 빈칸은 무조건 손해. 남은 1분에 빈칸을 전부 찍는다
- 시간 배분: 1~10번 10분, 11~20번 15분, 21~25번 15분
- 한 문제에 3분 넘게 막히면 표시하고 넘어간다
- **1~15번 실수 하나 = 21~25번 하나 = 똑같은 1점.** 쉬운 문제에서 not, least, greatest, 단위를 다시 읽는다

**직관 예시**
21~25번 다섯 문제 중 하나를 푸는 데 8분 쓰는 것보다, 앞 문제 다섯 개를 30초씩 다시 확인하는 게 기대 점수가 더 높을 때가 많다.

**선택지로 거르는 방법**
- 홀짝, 일의 자리, 3이나 9의 배수 여부로 지우기
- 크기 어림: 답이 대략 50이면 7이나 500은 바로 지운다
- **특수값 대입**: "모든 x에 대해", "임의의 삼각형" → x = 0, 1이나 정삼각형, 직각삼각형으로 계산해도 된다
- **선택지 대입** (8-6): 가운데부터

**어림값**
- $\pi \approx 3.14$, $\sqrt{2} \approx 1.414$, $\sqrt{3} \approx 1.732$, $\sqrt{5} \approx 2.236$
- $\sqrt{50} \approx 7.07$, $2^{10} \approx 1000$

**21~25번 고르는 법**
- 다 읽는 데 1분 쓰고, 아는 유형부터 푼다. 번호 순서대로 풀 필요 없다
- 경우의 수·정수론 문제는 "작은 경우부터"로 부분적으로라도 접근 가능
- 정말 모르겠으면 선택지 거르기 후 찍기

**함정**
- 어려운 문제에 매달리다 쉬운 문제 검토 시간을 날림
- OMR 밀려 쓰기. 5문제마다 번호 확인
