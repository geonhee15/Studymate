## 유닛 4. 정수론 2 (Number Theory II)

### 4-1. 나머지 연산 (Modular Arithmetic)

**왜 배우나**
엄청 큰 수의 나머지, 요일 계산, 주기 문제는 숫자를 다 계산하지 않고 나머지끼리만 계산하면 바로 풀린다.

**기초 설명**
- $a \equiv b \pmod{m}$: a와 b를 m으로 나눈 나머지가 같다
- 더하기, 빼기, 곱하기, 거듭제곱은 **나머지끼리 계산해도 된다**
- 나누기는 함부로 하면 안 된다
- 음수 나머지도 쓸 수 있다: $99 \equiv -1 \pmod{100}$, $10 \equiv -1 \pmod{11}$

**직관 예시**
시계는 mod 12다. 10시에서 5시간 후는 15시가 아니라 3시.
요일은 mod 7. 오늘이 금요일이면 100일 후는 100 = 7 × 14 + 2 → 금요일에서 2일 뒤 **일요일**.

**예제 풀이**

예제 1. $123456 \times 789$를 9로 나눈 나머지
1. 9로 나눈 나머지 = 자리합을 9로 나눈 나머지 (4-3)
2. 123456 → 21 → 3, 789 → 24 → 6
3. 3 × 6 = 18 → **0**

예제 2. $2^{100}$을 7로 나눈 나머지
1. $2^3 = 8 \equiv 1 \pmod 7$
2. $2^{99} = (2^3)^{33} \equiv 1$
3. $2^{100} = 2^{99} \cdot 2 \equiv$ **2**

예제 3. 3으로 나누면 2가 남고 5로 나누면 3이 남는 가장 작은 양의 정수
1. 5로 나누면 3: 3, 8, 13, 18, …
2. 이 중 3으로 나누면 2: 8 → **8**
3. 조건이 두 개면 "큰 나눗수 쪽 목록을 쓰고 작은 쪽으로 거르기"가 제일 빠르다

예제 4. $99^5$의 끝 두 자리
$99 \equiv -1 \pmod{100}$ → $(-1)^5 = -1 \equiv 99$ → **99**

**고급 팁**
- 거듭제곱은 **나머지가 1이 되는 지수**를 먼저 찾는다 (예제 2)
- 100 근처는 −1, 101 같은 걸 써서 계산을 줄인다
- 두 나머지 조건을 동시에 만족하는 수는 두 나눗수의 lcm마다 반복된다 (예제 3의 답 다음은 8 + 15 = 23)

**함정**
- 나머지를 음수나 m 이상으로 둔 채 답함
- 양변을 함부로 나눔

### 4-2. 일의 자리와 주기 (Units Digits & Cycles)

**왜 배우나**
"$7^{2026}$의 일의 자리"는 거의 매년 비슷한 모양으로 나온다. 주기만 알면 10초 문제.

**기초 설명**
- 곱의 일의 자리는 일의 자리끼리만 곱해서 정해진다 (mod 10)
- 거듭제곱 일의 자리 주기
  - 0, 1, 5, 6 → 항상 같음 (주기 1)
  - 4 → 4, 6 / 9 → 9, 1 (주기 2)
  - 2 → 2, 4, 8, 6 / 3 → 3, 9, 7, 1 / 7 → 7, 9, 3, 1 / 8 → 8, 4, 2, 6 (주기 4)
- 지수를 주기로 나눈 나머지로 위치를 찾는다. **나머지가 0이면 주기의 마지막**

**직관 예시**
$2^1 \sim 2^6$: 2, 4, 8, 16, 32, 64 → 일의 자리 2, 4, 8, 6, 2, 4 … 4개마다 반복.

**예제 풀이**

예제 1. $7^{2026}$의 일의 자리
1. 7의 주기: 7, 9, 3, 1
2. 2026 ÷ 4 → 나머지 2 → 두 번째 **9**

예제 2. $3^{2027} + 7^{2027}$의 일의 자리
1. 2027 ÷ 4 → 나머지 3
2. 3의 세 번째: 7, 7의 세 번째: 3
3. 7 + 3 = 10 → **0**

예제 3. $1! + 2! + \cdots + 100!$의 일의 자리
1. $5!$부터는 2 × 5가 들어 있어 끝자리 0
2. 1 + 2 + 6 + 24 = 33 → **3**

예제 4. $7^{2026}$의 끝 두 자리
1. $7^4 = 2401 \equiv 1 \pmod{100}$
2. 2026 = 4 × 506 + 2 → $7^{2026} \equiv 7^2 = 49$ → **49**

**고급 팁**
- 주기 4짜리는 지수를 4로 나눈 나머지만 보면 된다
- 끝 두 자리는 mod 100. $7^4$, $3^{20}$처럼 1이 되는 지수를 찾는다
- 합의 일의 자리는 각각의 일의 자리를 더한다 (예제 2)

**함정**
- 지수를 4로 나눈 나머지가 0일 때 "첫 번째"로 착각. 0이면 네 번째다. 예: $2^{100}$ → 6
- 밑의 일의 자리만 보면 되는데 밑 전체를 계산함

### 4-3. 배수 판정법 (Divisibility Rules)

**왜 배우나**
빈칸 숫자 찾기, "이 수가 ~의 배수가 되려면" 문제는 판정법을 거꾸로 쓰는 문제다.

**기초 설명**
| 수 | 판정 |
|---|---|
| 2 | 끝자리 짝수 |
| 3 | 자리합이 3의 배수 |
| 4 | 끝 두 자리가 4의 배수 |
| 5 | 끝자리 0 또는 5 |
| 6 | 2와 3 둘 다 |
| 8 | 끝 세 자리가 8의 배수 |
| 9 | 자리합이 9의 배수 |
| 11 | (홀수 번째 자리합) − (짝수 번째 자리합)이 11의 배수 (0 포함) |

- 왜 자리합인가: $10 \equiv 1 \pmod 9$라서 각 자리 숫자 × 자리값 ≡ 그 숫자 (mod 9)
- 왜 11은 교대합인가: $10 \equiv -1 \pmod{11}$이라 자리값이 +1, −1, +1 … 로 번갈아 감
- 합성수 판정은 서로소 조합으로: 12 = 3과 4, 36 = 4와 9, 72 = 8과 9

**직관 예시**
$4 \mid 100$이라 100 이상 자리는 4로 나눈 나머지에 영향이 없다. 그래서 끝 두 자리만 본다. 8은 $8 \mid 1000$이라 끝 세 자리.

**예제 풀이**

예제 1. 네 자리 수 $\overline{7A2B}$가 36의 배수일 때 가능한 수
1. 36 = 4 × 9
2. 4: 끝 두 자리 $\overline{2B}$가 4의 배수 → B = 0, 4, 8
3. 9: 7 + A + 2 + B = 9 + A + B가 9의 배수 → A + B = 0, 9, 18
4. B = 0 → A = 0 또는 9 → 7020, 7920
5. B = 4 → A = 5 → 7524
6. B = 8 → A = 1 → 7128
7. **4개**

예제 2. 918082는 11의 배수인가
1. 홀수 번째 자리(9, 8, 8) 합 25, 짝수 번째(1, 0, 2) 합 3
2. 25 − 3 = 22 → 11의 배수. **맞다**

예제 3. $\overline{abcabc}$ 꼴의 수는 항상 7, 11, 13의 배수
$\overline{abcabc} = \overline{abc} \times 1001 = \overline{abc} \times 7 \times 11 \times 13$

**고급 팁**
- 빈칸 두 개짜리는 **제약이 센 조건(끝자리 쪽)부터** 정하고 나머지를 맞춘다 (예제 1)
- 7은 판정법보다 1001 = 7 × 11 × 13을 이용해 세 자리씩 끊는 게 빠를 때가 많다

**함정**
- 4는 끝 두 자리, 8은 끝 세 자리인데 혼동
- 11 판정에서 차가 음수나 0이면 아니라고 착각. 0, −11도 11의 배수

### 4-4. 홀짝 (Parity)

**왜 배우나**
"가능한가?" 문제의 절반은 홀짝으로 끝난다. 선택지 지우기에도 최고.

**기초 설명**
- 짝 + 짝 = 짝, 홀 + 홀 = 짝, 짝 + 홀 = 홀
- 곱: 하나라도 짝이면 짝, 전부 홀이어야 홀
- 홀수를 홀수 개 더하면 홀, 짝수 개 더하면 짝
- 0은 짝수

**직관 예시**
1 + 2 + … + 10 = 55, 홀수. 어떤 수 앞의 +를 −로 바꾸면 합이 그 수의 2배만큼 줄어든다. 짝수만큼 변하니까 홀짝은 그대로.

**예제 풀이**

예제 1. 1부터 10까지 각 수 앞에 + 또는 −를 붙여 합을 0으로 만들 수 있나
1. 전부 +일 때 55 (홀)
2. 부호 하나 바꿀 때마다 2a씩 변함 → 홀짝 불변
3. 0은 짝수 → **불가능**

예제 2. 모임에서 홀수 번 악수한 사람 수는 항상 짝수
1. 모든 사람의 악수 횟수를 더하면 악수 한 번이 두 사람에게 세어져서 (전체 악수 수) × 2 = 짝수
2. 짝수 합 안에서 홀수 항의 개수는 짝수여야 한다

예제 3. 선택지 지우기
- $n(n+1)$은 항상 짝수 (연속 두 수 중 하나는 짝수)
- 연속 세 정수의 곱은 항상 6의 배수
- 답이 홀수여야 하는 문제에서 짝수 선택지는 바로 지운다

**고급 팁**
- **체스판 색칠 논법**: 8×8 체스판에서 마주 보는 두 귀퉁이 칸을 빼면 도미노 31개로 덮을 수 없다. 도미노는 항상 흰 칸 1개, 검은 칸 1개를 덮는데, 귀퉁이 둘은 같은 색이라 흰색과 검은색 개수가 30과 32로 달라지기 때문.
- "가능한가?"가 나오면 먼저 홀짝, 그다음 3이나 4로 나눈 나머지를 확인 (불변량, 유닛 9-2)

**함정**
- 0을 홀수 취급
- 홀짝은 "불가능"을 증명할 뿐, 홀짝이 맞는다고 가능한 건 아님

### 4-5. 진법 (Number Bases)

**왜 배우나**
2진법, 5진법 변환은 가끔 직접 나오고, 저울추나 동전 문제로 숨어서도 나온다.

**기초 설명**
- b진법 $\overline{d_k \cdots d_1 d_0}_b = d_k b^k + \cdots + d_1 b + d_0$
- 각 자리 숫자는 0 이상 b 미만
- 10진법 → b진법: b로 계속 나누면서 나머지를 적고 **거꾸로** 읽는다
- 또는 큰 거듭제곱부터 빼기: 2진법이면 1024, 512, 256 … 들어가는지

**직관 예시**
$1011_2 = 8 + 0 + 2 + 1 = 11$. 2진법은 "1, 2, 4, 8 … 중 어떤 걸 쓰나"를 0과 1로 적은 것.

**예제 풀이**

예제 1. 2026을 2진법으로
1. 2026 = 1024 + 512 + 256 + 128 + 64 + 32 + 8 + 2
2. $2^{10}, 2^9, 2^8, 2^7, 2^6, 2^5, 2^3, 2^1$ 자리가 1
3. **11111101010**₂

예제 2. 3 이상인 모든 b에 대해 $121_b$는 완전제곱수
$121_b = b^2 + 2b + 1 = (b+1)^2$

예제 3. 5진법 수의 끝자리 = 그 수를 5로 나눈 나머지 (10진법 끝자리가 10으로 나눈 나머지인 것과 같은 원리)

**고급 팁**
- 저울추 1, 2, 4, 8, …g로 한쪽 접시에만 올려 모든 무게 → 2진법
- 1, 3, 9, 27g로 양쪽 접시 다 쓰면 → 각 추가 −1, 0, +1 → 균형 3진법
- b진법 수가 b−1로 나누어떨어지는지 = 자리합이 b−1로 나누어떨어지는지 (10진법의 9 판정과 같음)

**함정**
- 나머지를 거꾸로 안 읽음
- 자리 숫자가 b 이상인 걸 허용함 (5진법에 숫자 5가 나오면 틀린 것)
