## 유닛 8. 대수, 문장제, 통계 (Algebra, Word Problems, Statistics)

### 8-1. 변수 잡는 법과 방정식

**왜 배우나**
AMC 8 문장제는 식만 제대로 세우면 계산은 쉽다. 어디에 x를 두느냐가 시간을 결정한다.

**기초 설명**
- 모르는 것 중 **하나**를 x로 두고 나머지를 x로 표현
- 문장 → 식 번역: "~보다 3 큰" → +3, "~의 2배" → ×2, "~이다" → =
- 연립방정식: 한 식을 다른 식에 대입하거나, 식끼리 더하고 빼기

**직관 예시**
연속한 정수 다섯 개. 가장 작은 걸 x로 두면 x, x+1, …, x+4. 가운데를 x로 두면 x−2, x−1, x, x+1, x+2 → 더하면 5x로 깔끔. 대칭인 것의 **가운데를 x로**.

**예제 풀이**

예제 1. 연속한 정수 5개의 합이 2025. 가장 큰 수는?
1. 가운데 x → 5x = 2025 → x = 405
2. 가장 큰 수 **407**

예제 2. 아버지 나이가 아들의 3배, 12년 뒤에는 2배
1. 아들 a, 아버지 3a
2. 3a + 12 = 2(a + 12) → a = 12
3. 아들 12세, 아버지 **36세**

예제 3. 닭과 돼지 합쳐 머리 20개, 다리 56개
1. 전부 닭이라 가정 → 다리 40개
2. 16개 남음. 닭 한 마리를 돼지로 바꿀 때마다 다리 2개 증가 → 8마리
3. 돼지 **8**, 닭 **12**
4. "전부 ~라고 가정하고 차이로 조정"은 식 없이 푸는 강력한 방법

예제 4. x + y = 10, y + z = 14, z + x = 12일 때 x + y + z
1. 세 식을 다 더하면 2(x + y + z) = 36
2. **18**. 각각 구할 필요 없다

**고급 팁**
- 물어보는 게 x + y + z처럼 **조합**이면 각각 구하지 말고 식을 통째로 더하거나 뺀다
- 미지수가 많으면 비례상수 k 하나로 묶는다 (8-2)
- 답 선택지가 숫자면 **대입(backsolving)**: 가운데 선택지부터 넣어서 크면 작은 쪽, 작으면 큰 쪽 (8-6)

**함정**
- "A는 B보다 3 적다"를 A − 3 = B로 거꾸로 씀. 작은 숫자로 확인: B = 10이면 A = 7 → A = B − 3
- 단위가 섞임 (분과 시간)

### 8-2. 비와 비례, 퍼센트 (Ratios & Percent)

**왜 배우나**
비율, 할인, 농도는 매년 쉬운 번호대에 나온다. 쉬운 문제라 실수 하나가 치명적이다.

**기초 설명**
- a : b = 2 : 3 → a = 2k, b = 3k로 놓는다
- 퍼센트 증감은 **곱**: 20% 증가 → ×1.2, 20% 감소 → ×0.8
- 연속 증감은 곱을 이어서: 20% 올리고 20% 내리면 1.2 × 0.8 = 0.96 → 4% 감소
- 자주 쓰는 분수: 12.5% = $\frac{1}{8}$, 20% = $\frac{1}{5}$, 25% = $\frac{1}{4}$, $33\frac{1}{3}$% = $\frac{1}{3}$, 37.5% = $\frac{3}{8}$, 62.5% = $\frac{5}{8}$, $66\frac{2}{3}$% = $\frac{2}{3}$, 75% = $\frac{3}{4}$

**직관 예시**
가격 100원이 25% 올라 125원. 다시 100원으로 내리려면 25원 내려야 하는데, 이건 125원의 20%. 기준이 바뀌었으니까.

**예제 풀이**

예제 1. A : B = 2 : 3, B : C = 4 : 5일 때 A : B : C
1. 공통인 B를 3과 4의 최소공배수 12로 맞춤
2. A : B = 8 : 12, B : C = 12 : 15
3. **8 : 12 : 15**

예제 2. 25% 올린 가격을 원래대로 돌리려면 몇 % 내려야 하나
1.25 × (1 − p) = 1 → 1 − p = 0.8 → **20%**

예제 3. 10% 소금물 200g에 물을 얼마나 넣어야 8%가 되나
1. 소금 20g은 그대로
2. 20 ÷ (200 + x) = 0.08 → 200 + x = 250
3. **50g**

**고급 팁**
- 농도·혼합 문제는 **변하지 않는 양**(소금)을 기준으로 식을 세운다
- 퍼센트를 분수로 바꾸면 계산이 정수로 떨어지는 경우가 많다
- 비가 세 개 이상 엮이면 공통 항을 최소공배수로 맞춘다

**함정**
- "A가 B보다 25% 크다"와 "B가 A보다 25% 작다"는 다르다. A = 1.25B면 B = 0.8A, 즉 B는 A보다 20% 작다
- 연속 할인을 더함 (20% + 10% ≠ 30%, 실제로는 1 − 0.8 × 0.9 = 28%)

### 8-3. 속력, 거리, 시간과 일의 양 (Rate Problems)

**왜 배우나**
속력·일 문제는 공식은 하나인데 함정이 많다. 특히 평균 속력.

**기초 설명**
- 거리 = 속력 × 시간
- **평균 속력 = 총 거리 ÷ 총 시간** (속력들의 평균이 아님)
- 마주 보고 오면 두 속력을 더하고, 같은 방향으로 쫓아가면 뺀다
- 일: "혼자 하면 t시간" → 1시간에 $\frac{1}{t}$만큼. 같이 하면 더한다

**직관 예시**
갈 때 시속 60, 올 때 시속 40. "평균 50"이 아니다. 느린 속도로 더 오래 달렸으니까 평균은 50보다 느리다.

**예제 풀이**

예제 1. 갈 때 시속 60, 올 때 시속 40으로 같은 길 왕복. 평균 속력은?
1. 편도 거리 120으로 잡음 (60과 40의 공배수)
2. 갈 때 2시간, 올 때 3시간 → 총 240 ÷ 5
3. **시속 48**
4. 공식: $\frac{2ab}{a + b} = \frac{2 \cdot 60 \cdot 40}{100} = 48$

예제 2. 30km 떨어진 두 사람이 시속 4km, 6km로 마주 보고 걸음. 만나는 데 걸리는 시간
가까워지는 속력 10 → 30 ÷ 10 = **3시간**

예제 3. 수조를 채우는 관 A는 4시간, 빼는 관 B는 6시간. 둘 다 열면
1. 1시간에 $\frac{1}{4} - \frac{1}{6} = \frac{1}{12}$
2. **12시간**

**고급 팁**
- 거리를 모르면 **계산하기 편한 값(공배수)으로 직접 정한다** (예제 1)
- 시간이 같으면 거리비 = 속력비, 거리가 같으면 시간비 = 속력의 역비
- 일 문제도 "전체 일의 양 = 12" 같은 공배수로 잡으면 분수가 사라진다

**함정**
- 평균 속력을 산술평균으로 계산
- 분 단위와 시간 단위 섞임 (20분 = $\frac{1}{3}$시간)

### 8-4. 평균, 중앙값, 최빈값, 범위 (Statistics)

**왜 배우나**
통계 문제는 매년 나온다. 평균은 "합"으로 바꾸는 순간 쉬워진다.

**기초 설명**
- 평균 = 합 ÷ 개수 → 그래서 **합 = 평균 × 개수**
- 중앙값: 크기순으로 줄 세워 가운데. 짝수 개면 가운데 두 개의 평균
- 최빈값: 가장 많이 나온 값. "유일한 최빈값"이면 다른 값은 그보다 적게 나와야 함
- 범위 = 최댓값 − 최솟값

**직관 예시**
평균 85점을 4번 받으면 총점 340. 평균이 주어지면 일단 합으로 바꿔 놓고 시작.

**예제 풀이**

예제 1. 시험 4번 평균 85점. 5번째에 몇 점을 받아야 평균 87?
1. 지금 합 340, 목표 합 87 × 5 = 435
2. **95점**

예제 2. 양의 정수 5개의 평균 10, 중앙값 9, 유일한 최빈값 8. 가장 큰 수의 최댓값은?
1. 합 50. 크기순으로 a ≤ b ≤ 9 ≤ d ≤ e
2. 8이 유일한 최빈값이려면 두 번 이상 → a = b = 8
3. d가 9면 9도 두 번이라 최빈값이 겹침 → d ≥ 10
4. e를 크게 하려면 d를 최소로: d = 10 → e = 50 − 8 − 8 − 9 − 10 = **15**
5. 확인: 8, 8, 9, 10, 15

예제 3. 평균 20인 수 10개에 31을 하나 더하면 새 평균은?
1. 합 200 + 31 = 231, 개수 11
2. **21**

**고급 팁**
- **최대를 원하면 나머지를 최소로** (예제 2). 극단 원리 (유닛 9-4)
- 기준값을 정하고 차이만 더하면 평균 계산이 빠르다: 90, 85, 95, 88 → 90 기준으로 0, −5, +5, −2 → 합 −2 → 평균 90 − 0.5 = 89.5
- 값 하나를 바꿨을 때 평균 변화 = (바뀐 양) ÷ 개수

**함정**
- 짝수 개일 때 중앙값을 가운데 하나로 씀
- 정렬 안 하고 가운데를 고름
- "유일한" 최빈값 조건을 놓침

### 8-5. 수열과 패턴 (Sequences)

**왜 배우나**
등차수열 합, 개수 세기는 쉬운 번호대에, 규칙 찾기는 어려운 번호대에 나온다.

**기초 설명**
- 등차수열: 첫째 항 a, 공차 d → n번째 항 $a + (n-1)d$
- 개수 = $\frac{\text{끝} - \text{처음}}{d} + 1$
- 합 = $\frac{(\text{처음} + \text{끝}) \times \text{개수}}{2}$
- 홀수 n개의 합 = $n^2$, 1부터 n까지 합 = $\frac{n(n+1)}{2}$ (삼각수)
- 등비: $1 + 2 + 4 + \cdots + 2^{n-1} = 2^n - 1$

**직관 예시**
1 + 2 + … + 100. 앞뒤를 짝지으면 (1 + 100), (2 + 99), … 101짜리가 50쌍 → 5050.

**예제 풀이**

예제 1. 7, 12, 17, …, 97의 항 수와 합
1. 개수 $\frac{97 - 7}{5} + 1 = $ **19**
2. 합 $\frac{(7 + 97) \times 19}{2} = $ **988**

예제 2. 1부터 99까지 홀수의 합
홀수 50개 → $50^2 = $ **2500**

예제 3. 100m 길에 10m 간격으로 양 끝 포함 나무를 심으면
$\frac{100}{10} + 1 = $ **11그루** (울타리 기둥 문제)

**고급 팁**
- 규칙이 안 보이면 **이웃한 항의 차(계차)**를 적어본다. 차가 일정하거나 차의 차가 일정한 경우가 많다
- 큰 번째 항은 주기를 찾는다 (유닛 4-2)

**함정**
- 개수에서 +1 빠뜨림 (off-by-one)
- 원형 길에 심을 땐 +1이 없다 (시작과 끝이 같은 점)

### 8-6. 그래프·표 읽기와 선택지 대입 (Graphs & Backsolving)

**왜 배우나**
그래프 문제는 쉬운데 눈금을 잘못 읽어서 틀린다. 대입은 식 세우기 귀찮은 문제를 빠르게 끝낸다.

**기초 설명**
- 그래프: 축 이름, 단위, **눈금 간격**부터 확인. 0에서 시작 안 하는 축 주의
- 원그래프: 퍼센트 × 3.6 = 각도
- 대입(backsolving): 답 선택지는 보통 크기순. **가운데 (C)부터** 넣어보고 너무 크면 작은 쪽, 작으면 큰 쪽 → 최대 2~3번이면 끝

**직관 예시**
"어떤 수에 그 수의 $\frac{1}{3}$을 더했더니 48" → 선택지가 24, 30, 36, 40, 42면 36 넣어보기: 36 + 12 = 48. 끝.

**예제 풀이**

예제 1. 원그래프에서 25%인 부분의 중심각: 25 × 3.6 = **90°**

예제 2. 막대그래프 세로축이 50부터 시작하면 막대 길이 비율이 실제 값 비율과 다르다. 값은 눈금으로만 읽는다.

**고급 팁**
- 대입은 "조건을 만족하는 수를 구하시오" 유형에 특히 강하다
- 그래프 문제는 문제를 먼저 읽고 필요한 칸만 본다

**함정**
- 눈금 한 칸이 1이 아니라 2, 5, 10일 수 있음
- 누적 그래프와 일반 그래프 혼동
