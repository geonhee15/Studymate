## 유닛 2. 세는 법 2 (Counting II)

### 2-1. 순열과 조합 (Permutations & Combinations)

**왜 배우나**
"몇 명을 뽑는다", "일렬로 세운다"는 AMC 경우의 수의 기본 뼈대다. 순서를 따지는지 판단만 정확하면 절반은 끝난다.

**기초 설명**
- 순열 $P(n, r) = \frac{n!}{(n-r)!}$: n개 중 r개를 **순서 있게** 나열
- 조합 $\binom{n}{r} = \frac{n!}{r!\,(n-r)!}$: n개 중 r개를 **순서 없이** 고름
- 판단: 고른 것들의 자리를 바꿨을 때 **다른 결과인가?** 회장·부회장이면 다름(순열), 위원 3명이면 같음(조합)
- 성질
  - $\binom{n}{r} = \binom{n}{n-r}$ (r개 고르기 = 안 고를 n−r개 고르기)
  - $\binom{n}{0} + \binom{n}{1} + \cdots + \binom{n}{n} = 2^n$ (부분집합 전체)
  - 파스칼: $\binom{n}{r} = \binom{n-1}{r-1} + \binom{n-1}{r}$ (특정 한 명을 뽑냐 안 뽑냐)

**직관 예시**
A, B, C, D 중 2명 뽑기.
- 순서 있게: 4 × 3 = 12 (AB, BA, AC, CA, …)
- 순서 없이: AB와 BA가 같으니 각 쌍이 2번씩 → 12 ÷ 2 = 6
- 조합 = 순열 ÷ (고른 것끼리 줄 세우는 수)

**예제 풀이**

예제 1. 10명 중 회장, 부회장, 서기 각 1명 / 위원 3명
- 직책이 다름 → 순열: 10 × 9 × 8 = **720**
- 위원은 같은 자격 → 조합: $\binom{10}{3} = 720 \div 3! = $ **120**

예제 2. 남학생 5명, 여학생 4명 중 4명을 뽑을 때 여학생이 적어도 1명
1. 여사건: 전체 $\binom{9}{4} = 126$
2. 전부 남학생 $\binom{5}{4} = 5$
3. 126 − 5 = **121**

예제 3. 원 위의 점 8개
- 꼭짓점으로 만드는 삼각형: $\binom{8}{3} = 56$
- 볼록 팔각형 대각선끼리의 교점(세 대각선이 한 점에서 안 만날 때): 점 4개를 고를 때마다 교점 하나 → $\binom{8}{4} = 70$

예제 4. 남 4명, 여 3명이 일렬로 서는데 여자끼리 이웃하지 않게
1. 남자 먼저 세움: 4! = 24
2. 남자 사이사이와 양끝에 틈이 5개: _ 남 _ 남 _ 남 _ 남 _
3. 틈 5개 중 3개에 여자를 순서 있게: 5 × 4 × 3 = 60
4. 24 × 60 = **1440**

**고급 팁**
- 외워 두면 빠른 값: $\binom{5}{2}=10$, $\binom{6}{2}=15$, $\binom{7}{2}=21$, $\binom{8}{2}=28$, $\binom{10}{2}=45$, $\binom{6}{3}=20$, $\binom{8}{3}=56$, $\binom{10}{3}=120$
- **반드시 포함**되는 사람 → 미리 뽑아두고 나머지에서 고른다
- **반드시 붙어야** → 한 덩어리로 묶어서 세고, 덩어리 안 순서를 곱한다
- **붙으면 안 됨** → 나머지를 먼저 세우고 틈에 넣는다 (예제 4)
- 붙으면 안 되는 문제는 "전체 − 붙은 경우"로도 풀린다. 두 방법으로 풀어서 맞춰보면 검증이 된다

**함정**
- 직책이 있는데 조합을 씀, 또는 그 반대
- "위원 3명을 뽑고 그중 위원장 1명" = $\binom{10}{3} \times 3$. 위원장을 먼저 뽑으면 $10 \times \binom{9}{2}$. 둘 다 360이어야 정상. 한쪽만 다르게 나오면 중복이나 누락이 있다

### 2-2. 칸막이 (Stars and Bars)

**왜 배우나**
"같은 물건을 나눠 주기", "합이 n인 정수해 개수"는 공식 하나로 끝나는데, 모르면 손으로 세다 시간을 다 쓴다.

**기초 설명**
- **같은** 물건 n개를 **서로 다른** k명에게 나누기
  - 0개 받는 사람 허용: $\binom{n+k-1}{k-1}$
  - 모두 1개 이상: $\binom{n-1}{k-1}$
- 같은 말: $x_1 + x_2 + \cdots + x_k = n$의 음이 아닌 정수해 / 양의 정수해 개수

**직관 예시**
사탕 5개를 3명에게 (0개 허용).
★★|★|★★ 는 (2, 1, 2), |★★★★★| 는 (0, 5, 0).
별 5개와 막대 2개, 총 7칸에서 막대 자리 2개를 고르면 나눠주는 방법 하나가 정해진다 → $\binom{7}{2} = 21$

**예제 풀이**

예제 1. $x + y + z = 10$
- 양의 정수해: 별 10개 사이 틈 9개 중 칸막이 2개 → $\binom{9}{2} = $ **36**
- 음이 아닌 정수해: $\binom{12}{2} = $ **66**

예제 2. 사탕 12개를 4명에게, 각자 최소 2개
1. 먼저 2개씩 나눠줌 → 남은 4개
2. 남은 4개를 4명에게 0개 허용 → $\binom{7}{3} = $ **35**

예제 3. $x + y + z = 10$, 음이 아닌 정수, 각각 5 이하
1. 제한 없이: 66
2. x ≥ 6인 경우: x에서 6을 빼면 합이 4 → $\binom{6}{2} = 15$. y, z도 같음 → 45
3. 두 개가 동시에 6 이상이면 합이 12 이상이라 불가능
4. 66 − 45 = **21**

**고급 팁**
- **최소 조건** → 미리 나눠주고 시작
- **최대 조건** → 넘친 경우를 여사건·포함배제로 뺀다 (예제 3)
- 물건이 **서로 다르면** 칸막이가 아니다. 물건마다 k가지 선택 → $k^n$
- 받는 사람도 구분 안 되면(같은 상자들) 칸막이도 아니다. 작은 경우를 직접 나열한다

**함정**
- 양의 정수해 / 음이 아닌 정수해 공식 혼동
- 물건이 같은지 다른지 확인 안 함

### 2-3. 격자 경로 (Lattice Paths)

**왜 배우나**
"오른쪽과 위로만 가서 A에서 B까지" 문제는 거의 매년 형태를 바꿔 나온다.

**기초 설명**
- (0, 0)에서 (m, n)까지 오른쪽(R)과 위(U)로만: R m개, U n개를 나열하는 방법 → $\binom{m+n}{m}$
- 특정 점 P를 **지나는** 경로: (출발 → P) × (P → 도착)
- 특정 점을 **피하는** 경로: 전체 − 지나는 경로

**직관 예시**
오른쪽 2번, 위 1번이면 RRU, RUR, URR → 3가지 = $\binom{3}{1}$. 경로 = 글자 재배열 문제다.

**예제 풀이**

예제 1. (0,0) → (4,3): $\binom{7}{3} = $ **35**

예제 2. (0,0) → (4,3), 반드시 (2,1)을 지남
1. (0,0) → (2,1): $\binom{3}{1} = 3$
2. (2,1) → (4,3): 오른쪽 2, 위 2 → $\binom{4}{2} = 6$
3. 3 × 6 = **18**

예제 3. 같은 경로에서 (2,1)을 피함: 35 − 18 = **17**

**덧셈 표 방법**
각 교차점에 "그 점까지 오는 경로 수"를 적는다. 어떤 점의 값 = 왼쪽 점 값 + 아래 점 값. 맨 아래 줄과 맨 왼쪽 줄은 전부 1. 막힌 점은 0.
장애물이 여러 개거나 모양이 이상한 격자에선 이게 가장 빠르고 안전하다.

**고급 팁**
- 3차원 격자 (a, b, c): $\frac{(a+b+c)!}{a!\,b!\,c!}$
- 대각선 이동이 섞이거나 지나면 안 되는 구간이 여러 개 → 덧셈 표
- "같은 점을 두 번 지나지 않는" 같은 조건은 오른쪽·위로만 갈 땐 자동으로 만족

**함정**
- 칸 수와 선분 수 혼동: 4×3칸짜리 격자 그림이면 오른쪽 4번, 위 3번
- 출발점을 (1,1)로 잡고 하나씩 밀림

### 2-4. 확률 (Probability)

**왜 배우나**
AMC 8에서 매년 2~3문제. 대부분 "제대로 센 경우의 수 ÷ 전체"인데, 전체를 잘못 잡는 실수가 제일 많다.

**기초 설명**
- $P = \frac{\text{원하는 경우}}{\text{전체 경우}}$ **단, 모든 경우가 같은 확률로 일어날 때만**
- 독립인 사건이 연달아 일어남: 확률을 곱한다
- 동시에 일어날 수 없는 사건 중 하나: 확률을 더한다
- 여사건: $1 - P(\text{반대})$

**직관 예시**
주사위 2개의 합. 합은 2~12로 11가지지만 각 합의 확률이 다르다. 합 7은 (1,6), (2,5), …, (6,1) 6가지, 합 2는 (1,1) 1가지.
그래서 "합이 7일 확률 = 1/11"은 틀리고, 6×6 = 36칸 표로 세서 6/36 = 1/6이 맞다.

**예제 풀이**

예제 1. 주사위 2개의 합이 소수일 확률
1. 합 2: 1가지, 3: 2가지, 5: 4가지, 7: 6가지, 11: 2가지
2. 1 + 2 + 4 + 6 + 2 = 15
3. $\frac{15}{36} = \frac{5}{12}$

예제 2. 빨간 공 3개, 파란 공 2개에서 2개를 꺼낼 때(다시 넣지 않음) 둘 다 빨강
- 순서대로: $\frac{3}{5} \times \frac{2}{4} = \frac{3}{10}$
- 한꺼번에: $\frac{\binom{3}{2}}{\binom{5}{2}} = \frac{3}{10}$
- 두 방법이 같다. "순서대로 뽑기"와 "한꺼번에 뽑기"는 같은 확률

예제 3. 주사위 2개에서 첫 번째 눈이 두 번째보다 클 확률
1. 같을 확률 $\frac{6}{36} = \frac{1}{6}$
2. 나머지 $\frac{5}{6}$를 "첫째가 큼"과 "둘째가 큼"이 대칭으로 반씩 나눔
3. $\frac{5}{12}$

예제 4. 한 변이 2인 정사각형 다트판에 내접한 원 안에 떨어질 확률 (판 안 어디든 같은 확률)
넓이비: $\frac{\pi \cdot 1^2}{2^2} = \frac{\pi}{4}$

예제 5. A와 B가 번갈아 동전을 던져 먼저 앞면이 나오는 사람이 이김, A부터
1. A가 이길 확률을 p라 하자
2. A가 첫 판에 앞면: $\frac{1}{2}$
3. 첫 판 A 뒷면, B 뒷면이면 처음과 같은 상황으로 돌아옴: $\frac{1}{4} \cdot p$
4. $p = \frac{1}{2} + \frac{1}{4}p$ → $p = $ $\frac{2}{3}$

**고급 팁**
- **대칭성**: "A > B일 확률"은 $\frac{1 - P(A = B)}{2}$ (예제 3)
- 주사위 2개는 무조건 **6×6 표**
- **"다시 같은 상황"이 나오면 p로 놓고 방정식** (예제 5)
- 기하 확률은 넓이비, 길이비

**함정**
- 같은 확률이 아닌 결과로 나눔 (합 11가지)
- 다시 넣는지(복원) 안 넣는지(비복원) 확인 안 함
- 독립이 아닌 사건을 그냥 곱함

### 2-5. 기댓값 (Expected Value)

**왜 배우나**
21~25번에 가끔 나온다. 선형성 하나만 알면 어려워 보이는 문제가 한 줄로 끝난다.

**기초 설명**
- 기댓값 = Σ (값 × 그 값이 나올 확률) = "아주 많이 반복했을 때 평균"
- **선형성**: $E[X + Y] = E[X] + E[Y]$. X, Y가 독립이 아니어도 항상 성립

**직관 예시**
주사위 한 번: $\frac{1+2+3+4+5+6}{6} = 3.5$. 실제로 3.5가 나올 수는 없지만 평균은 3.5.

**예제 풀이**

예제 1. 주사위 2개 합의 기댓값: 선형성 → 3.5 + 3.5 = **7**

예제 2. 참가비 2점, 주사위에서 1이 나오면 6점 받는 게임의 기댓값
$6 \times \frac{1}{6} - 2 = $ **−1**. 할수록 손해.

예제 3. 5명이 모자를 섞어서 무작위로 하나씩 가져갈 때, 자기 모자를 가져가는 사람 수의 기댓값
1. 한 사람이 자기 모자를 가져갈 확률 $\frac{1}{5}$
2. 사람마다 "자기 거면 1, 아니면 0"을 더한 게 전체 수
3. 선형성 → 5 × $\frac{1}{5}$ = **1**
4. 사람이 100명이어도 답은 1

**고급 팁**
- 분포를 다 구하지 말고 **"하나씩 0 또는 1"로 쪼개서 더한다** (예제 3)
- 기댓값이 정수일 필요 없다

**함정**
- 선형성은 되는데 곱은 독립일 때만 $E[XY] = E[X]E[Y]$
